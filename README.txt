DYNAMIC IMAGE GALLERY VERSION

This version lets you add or remove images directly in the browser for:
- Profile
- About
- UTP / Education
- Internship
- Gold Planner
- BEST System
- IoT Project
- Web Application Project

HOW IT WORKS
1. Open index.html in a browser.
2. Click '+ Add Image' in any section.
3. Select one or multiple images.
4. Images appear immediately.
5. Click the × button on any image to remove it.

IMPORTANT
These browser-added images are preview-only for the current browser session.
If you refresh the page, the uploaded images disappear.

To make images permanent:
- copy your real images into the assets folder
- update the corresponding <img src="..."> paths in index.html

Also remember to replace:
- email
- LinkedIn URL
- GitHub URL
- Live Demo link
- project repository link
